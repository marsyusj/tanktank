# 坦克大战

基于 XGo / SPX 的俯视角坦克大战游戏，包含单人三关、双人合作、能源竞技、森林大围剿和单人地图编辑器。

## 运行

```sh
bash local.sh build
bash local.sh run
```

首次编译需要导入 Godot 资源，可能稍慢。关闭游戏窗口即可结束运行。

## 测试操作

- `N` 单人动态地图；方向键移动，空格开火。防守累计击毁达到本关目标，或反转后摧毁敌方基地，即可进入后续关卡。
- `J` 双人合作，`K` 能源竞技，`L` 无基地围剿。P1 使用 WASD 移动、空格开火；P2 使用方向键移动、Enter 开火。
- 围剿模式先按 `Z` 选单人或 `X` 选双人，再按 `L` 开始。
- `E` 进入单人地图编辑器，`1` 至 `4` 选砖、钢、水、林，`5` 擦除，`R` 清空，Enter 试玩。

## 攻守反转

三关都可在防守阶段累计击毁指定数量的敌军直接过关。若在达到累计目标之前 **10 秒内击毁 5 辆敌方坦克**，则触发反转；反转后必须向上摧毁敌方基地才能过关。同一击同时达到两项条件时优先按累计击毁过关。手雷击毁计入累计目标，不计入反转连击。

| 关卡 | 防守累计击毁过关 | 反转地图 | 同时出现的敌军 | 敌方基地耐久 | 敌军特点 |
| --- | ---: | --- | ---: | ---: | --- |
| 1 | 8 辆 | 两侧砖墙与少量钢板 | 2 | 6 | 基础坦克 |
| 2 | 15 辆 | 两侧砖墙与双侧河道 | 3 | 8 | 移动和开火更快 |
| 3 | 20 辆 | 基地前砖墙、水道、钢板和冰地 | 4 | 10 | 装甲或精英坦克，移动和开火进一步加快 |
